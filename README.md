# 🗼 과학 타워 레이스

초등 과학 3학년 2학기 복습 게임입니다. 층마다 문제를 풀고, 구역 끝 관문에서 정답을 직접 써서 탑 꼭대기까지 올라가요.
지금은 **2단원 「지구와 바다」**(문제 59개, 관문 13개)로 하고, **3단원 「소리의 성질」**(문제 50개 초안, 관문 10개)도 준비되어 있어요.

## 화면 세 가지

| 주소 | 누가 | 하는 일 |
|---|---|---|

## 1. GitHub Pages에 올리기

폴더 안의 파일을 **폴더 구조 그대로** 저장소에 올리고, Settings → Pages에서 배포하면 돼요.

Firebase를 설정하기 전에도 학생 게임의 **「혼자 연습」**과 **TV 미리보기(`?tv=demo`)**는 바로 돼요.

## 2. Firebase 연결 (교사 화면·TV 중계용, 처음 한 번만)

1. <https://console.firebase.google.com> 에서 **프로젝트 만들기** (애널리틱스는 꺼도 돼요)
2. 왼쪽 메뉴 **빌드 → Realtime Database → 데이터베이스 만들기** → 위치 **싱가포르(asia-southeast1)** → **테스트 모드**
3. **규칙** 탭에 아래를 붙여 넣고 **게시**
   ```json
   {
     "rules": {
       "rooms": {
         "$code": {
           ".read": true,
           ".write": true,
           ".validate": "$code.matches(/^[0-9]{4}$/)"
         }
       },
       "ranks": {
         ".read": true,
         ".write": true
       }
     }
   }
   ```
4. **프로젝트 설정(톱니바퀴) → 일반 → 내 앱 → 웹 앱 추가(`</>`)** → 이름만 쓰고 등록
5. 나오는 `firebaseConfig` 값을 **`firebase-config.js`** 에 붙여 넣고(파일 안 설명대로), 다시 올리기

> 무료(Spark) 요금제로 충분해요. 동시 접속 100명까지라 한 반 수업에는 넉넉해요.
> 저장되는 건 학생이 고른 **반·별명**과 게임 기록뿐이에요. 수업이 끝나면 교사 화면의 **「이 방 지우기」**로 지워 주세요.

## 3. 수업할 때

1. 교사 컴퓨터에서 `?teacher` 를 열고 단원을 골라 **방 만들기** → 4자리 방 번호가 나와요
2. **「TV 중계 화면 열기」**를 눌러 열린 창을 교실 TV로 보내고 「전체 화면」
   (대기 중일 때는 TV에 방 번호와 들어오는 주소가 크게 나와요)
3. 학생은 태블릿에서 게임 주소를 열고 **방 번호 · 반(1~7반) · 별명** 입력 → 대기실
4. 교사 화면에서 **게임 시작** → 모두 동시에 출발
5. 필요하면 **잠시 멈춤**(학생 화면·시간이 멈춤), **알림 보내기**, 학생별 **깃발로/처음부터/내보내기**
6. **게임 끝내기** → 학생 화면에 결과(다시 볼 문제), TV에 순위
7. 같은 방에서 한 판 더: **새 판 준비(대기실로)**

### 교사 설정

- **문제를 틀리면 돌아가는 곳**: 그 층 광장 / 그 층 처음(기본) / 구역 처음
- **관문** 켜기·끄기: 끄면 단답형 관문 없이 다음 구역으로 가요
- **문제 사진** 켜기·끄기
- **문제 관리**: 문제마다 끄고 켤 수 있고(다음 판부터 적용), 문제별 첫 시도 정답률이 보여요. 「많이 틀린 문제」에 상위 5개가 모여요

### 기록 랭킹

- 방에서 한 판을 마치면(정상 도착, 또는 교사가 게임을 끝냈을 때) 기록이 랭킹에 올라가요. 「혼자 연습」은 올라가지 않아요
- **점수 = 문제 점수 + 시간 점수** (문제 약 60%, 시간 약 40%)
  - 문제 점수: 한 번에 맞히면 40점, 다시 도전해서 맞히면 20점 (15층이면 최대 600점)
  - 시간 점수: 정상에 도착했을 때만. 400점에서 3초마다 1점씩 줄고 최소 100점 (5분 → 300점, 10분 → 200점)
  - 점수가 같으면 빨리 도착한 학생이 위
- 단원마다 따로 **반별 TOP 10**과 **학년 TOP 10**이 있어요. 같은 반·같은 별명은 한 사람으로 보고 가장 좋은 기록만 남아요 (별명은 겹치지 않게 지어 주세요)
- 학생 화면 왼쪽에 **반 1위·학년 1위**가 늘 보이고, 그 밑에 **내 순위**와 「지금 이 점수면 반 몇 위」가 보여요. 시작 화면·메뉴·결과 화면의 「랭킹 보기」로 전체 순위를 봐요
- 교사 화면의 **「랭킹 초기화」**를 누르면 모든 단원의 랭킹이 지워져요
- 학년·반 수와 점수 비율은 `js/rank.js` 맨 위에서 바꿔요 (`SCHOOL = { 3: 7 }` → 3학년 7반까지)
- ⚠️ Firebase 규칙을 이미 넣었다면 위 규칙으로 다시 게시해 주세요 (`ranks` 부분이 새로 생겼어요)

## 4. 문제 고치기

| 파일 | 내용 |
|---|---|
| `units/unit2.js` | 2단원 「지구와 바다」 문제·관문·구역 (선생님 「과학 정원 지키기」 문제 59개를 옮김) |
| `units/unit3.js` | 3단원 「소리의 성질」 **초안** — 교과서와 맞춰 확인해 주세요 |
| `img/unit2/` | 2단원 문제 사진 36장 |
| `img/unit3/` | 3단원 문제 사진 넣을 곳 (비어 있음) |

문제 한 개는 이렇게 생겼어요.

```js
{ id: "u3-302", zone: 3, q: "실로폰에서 높은 소리가 나는 음판은?", options: ["짧은 음판", "긴 음판", "모두 같아요"], answer: 0, explain: "음판이 짧을수록 높은 소리", img: "xylophone.jpg" },
```

- `options`는 3~4개, `answer`는 정답의 순서(0부터). 보기가 4개면 정답 + 오답 2개를 골라 세 발판에 내요 (보기 순서는 매번 섞여요)
- `img`는 `img/unit3/` 안의 사진 파일 이름 (없으면 빼요)
- 관문은 `gates`에 `{ zone: 1, q: "…□□…", answers: ["떨림"] }` 처럼. 틀리면 초성 → 첫 글자 → 정답 순서로 힌트가 나와요
- 3단원 확인이 끝나면 `draft: true` 줄을 지우면 교사 화면의 「초안」 표시가 사라져요

### 다른 단원 더하기

`units/unit3.js`를 복사해 `id`, `no`, `title`, 문제를 바꾸고, `index.html` 아래쪽 `<script src="units/unit3.js">` 다음 줄에 새 파일을 한 줄 더하면 시작 화면·교사 화면에 단원이 생겨요.
구역 `obstacles`로 장애물을 고를 수 있어요: `pad`(보통) `wind`(바람) `hurdle`(벽) `spinner`(회전 막대) `cross`(십자 막대) `crumble`(무너지는 발판) `mover`(움직이는 발판) `lift`(오르내리는 발판) `bouncy`(통통 발판)

## 21차: 바로 입장 · 언제든 합류 · 구경하기 (2026-10-31)

첨부한 「stage20」에서 고화질 디자인과 수정을 골라 넣고, 입장 방식을 바꿨어요.

### 학생
- 첫 화면 → 반·별명·캐릭터 → **「게임 시작」을 누르면 바로 출발**해요. 대기실·방 번호·혼자 연습 탭이 없어요.
- 모든 학생(1~7반)이 **같은 타워**에서 함께 뛰어요. **중간에 들어와도** 바로 1층부터 출발하고, 먼저 뛰고 있는 친구들이 화면에 보여요.
- **「👀 친구들 게임 구경하기」**(시작 화면·결과 화면): 게임을 하지 않고 친구들을 중계 화면으로 봐요. 「🎮 나도 게임하러 가기」로 돌아와요.
- 정상에 도착한 뒤 「다시 하기」로 바로 한 판 더 할 수 있어요.
- Firebase가 아직 없으면 혼자 도전 모드로 바로 시작해요(이때만 문제 고르기 카드가 보여요).

### 선생님 (`?teacher`)
- 시작 버튼이 없어요. **교실은 늘 열려 있고**, 선생님 화면을 열지 않아도 첫 학생이 들어오면 교실이 열려요(2단원).
- **잠시 멈춤 / 다시 시작**: 모든 학생 화면이 멈췄다 이어져요. 멈춘 동안 들어온 학생도 함께 멈춰요.
- **모두 끝내기**: 모든 학생에게 결과 화면이 나오고 기록이 랭킹에 올라가요.
- **새 판 열기**: 이번 판 기록을 지우고 모두 1층부터 다시 출발해요.
- **오늘 풀 문제** 바꾸기: 언제든 바꿀 수 있고, 게임 중인 학생도 새 문제로 1층부터 출발해요.
